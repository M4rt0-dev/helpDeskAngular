# HelpDesk

Aplicacion sencilla de gestion de incidencias hecha con Angular.

Permite iniciar sesion con distintos roles, crear tickets, asignarlos, cambiar estados, ver notificaciones y revisar logs de seguridad.

## Requisitos

- Node.js
- npm

## Como arrancarlo

```bash
npm install
npm start
```

Luego abre:

```bash
http://localhost:4200
```

## Comandos utiles

```bash
npm start
npm run build
npm test
```
